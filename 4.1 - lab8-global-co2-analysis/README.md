# Анализ глобальных выбросов CO₂

Данный проект представляет собой лабораторную работу №8, посвящённую анализу исторических данных о выбросах углекислого газа (CO₂) в атмосферу.

Анализ выполнен на основе открытого датасета от проекта **Our World in Data** и включает в себя:
- Очистку и предварительную обработку данных.
- Выявление стран-лидеров по совокупным выбросам CO₂.
- Исследование динамики выбросов по десятилетиям.
- Сравнение объёмов выбросов по континентам.
- Анализ временных трендов для топ-5 стран.

## 📊 Результаты анализа

В результате работы были получены следующие ключевые выводы:

- **Лидером** по совокупным выбросам CO₂ является **Соединённые Штаты**, за которыми следуют Китай и Россия.
- Общие выбросы по десятилетиям демонстрируют устойчивый рост с середины XX века, достигнув пика в 2010-х годах.
- В **2024 году** доминирующим континентом по объёму выбросов является **Азия**, на долю которой приходится более 62% от анализируемых стран.

## 🖼️ Визуализация данных

Проект включает в себя ряд графиков для наглядного представления результатов:

- `co2_by_decade.png`: Суммарные выбросы CO₂ по десятилетиям (1750–2017).
- `top10_countries_co2.png`: Топ-10 стран по совокупным выбросам.
- `top5_countries_timeline.png`: Динамика выбросов для топ-5 стран во времени.
- `continents_co2.png`: Сравнение выбросов по континентам за последний год в датасете.
