# Fashion MNIST Image Classification with Neural Networks

Этот проект демонстрирует построение и сравнение нескольких архитектур нейронных сетей для классификации изображений из набора данных **Fashion MNIST**. Цель — достичь точности на тестовых данных выше **90%**.

## 📌 Основной результат

Лучшая достигнутая точность: **93.69%**  
Архитектура-победитель: **Оптимизированная сверточная нейронная сеть (CNN)**

## 🧠 Используемые технологии

- **TensorFlow/Keras** — фреймворки для глубокого обучения.
- **Python** — основной язык программирования.
- **NumPy, Pandas, Matplotlib** — для обработки и визуализации данных.
- **Jupyter Notebook** — среда для разработки и экспериментов.
- **Fashion MNIST** — датасет из 70 000 изображений 10 классов модной одежды.

## 🏆 Сравнение моделей

| Архитектура               | Точность на тесте | Время обучения (мин) |
|---------------------------|-------------------|----------------------|
| Оптимизированная CNN      | **93.69%**        | 14.54                |
| Базовая CNN               | 91.90%            | 4.85                 |
| Полносвязная сеть (MLP)   | 88.56%            | 0.42                 |

### Особенности победившей архитектуры:
- Свёрточные слои (`Conv2D`) с batch normalization.
- Dropout для регуляризации.
- Callback'и: `EarlyStopping` и `ReduceLROnPlateau`.
- Использование оптимизатора `RMSprop`.

## 📊 Описание датасета

**Fashion MNIST** — это альтернатива классическому MNIST, где вместо цифр используются изображения модной одежды (28×28 пикселей в оттенках серого).

Классы:
- `0: Футболка`
- `1: Брюки`
- `2: Свитер`
- `3: Платье`
- `4: Пальто`
- `5: Туфли`
- `6: Рубашка`
- `7: Кроссовки`
- `8: Сумка`
- `9: Ботинки`
