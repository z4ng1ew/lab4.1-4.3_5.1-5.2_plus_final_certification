# Прогнозирование цен на подержанные автомобили Toyota

Данный проект представляет собой регрессионную модель машинного обучения для предсказания стоимости подержанных автомобилей марки Toyota на основе их технических характеристик и рыночных данных.

![Пример визуализации](https://via.placeholder.com/800x400?text=Model+Performance+Visualization)

## Описание

Проект анализирует датасет с информацией о подержанных автомобилях, включая такие параметры, как год выпуска, пробег, налог, расход топлива и объем двигателя. Целью является построение точной модели для предсказания рыночной цены автомобиля.

Анализ показал высокое качество модели: коэффициент детерминации (R²) превышает 0.75, что означает, что модель объясняет более 75% дисперсии целевой переменной (цены).

## Используемые технологии

- **Язык программирования**: Python
- **Библиотеки для анализа данных**: 
  - `pandas`
  - `numpy`
- **Библиотеки для машинного обучения**:
  - `scikit-learn` (линейная регрессия)
- **Библиотеки для визуализации**:
  - `matplotlib`
  - `seaborn`

## Структура проекта

- `toyota.csv` — исходный датасет с данными об автомобилях.
- Основной скрипт (Jupyter Notebook или Python-файл) для:
  - Загрузки и предварительной обработки данных.
  - Построения и оценки регрессионной модели.
  - Визуализации результатов.

## Как запустить

1. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите Jupyter Notebook или Python-скрипт.

## Результаты

- Построена и оценена линейная регрессионная модель.
- Коэффициент детерминации (R²) для финальной модели: **> 0.75**.
- Определены ключевые факторы, влияющие на стоимость автомобиля.
