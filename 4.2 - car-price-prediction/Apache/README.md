## 📊 Лабораторная работа №8: Анализ выбросов CO₂ и регрессионное моделирование цен автомобилей

Этот проект включает два независимых аналитических блока:

1. **Анализ исторических и современных выбросов CO₂ по странам и континентам**  
2. **Прогнозирование рыночной цены подержанных автомобилей с помощью линейной регрессии**

---

### 🌍 Часть 1: Анализ выбросов CO₂

**Цель:**  
Исследовать динамику выбросов углекислого газа с 1750 по 2024 год, выявить лидирующие страны и континенты, а также визуализировать долгосрочные и современные тенденции.

**Используемые данные:**  
Датасет [`owid-co2-data.csv`](https://github.com/owid/co2-data) от Our World in Data.

**Ключевые результаты:**
- **США** — исторический лидер по совокупным выбросам (более 559 Гт).
- **Азия** — доминирующий континент по выбросам в 2024 году (62.5% от анализируемого объёма).
- Выявлен резкий рост выбросов с середины XX века, с пиком темпов роста в 1960–1970-х годах.

**Визуализации:**
- Глобальные выбросы CO₂ по десятилетиям.
- Топ-10 стран по историческим выбросам.
- Эволюция годовых выбросов для топ-5 стран.
- Распределение выбросов по континентам в 2024 году.

---

### 🚗 Часть 2: Прогнозирование цен на автомобили

**Цель:**  
Построить и сравнить две модели линейной регрессии для предсказания цены автомобиля на основе его характеристик.

**Используемые данные:**  
Датасет `car_data.csv` с числовыми признаками: `year`, `mileage`, `tax`, `mpg`, `engineSize`.

**Ключевые результаты:**
- **Модель 1** (все признаки): `R² = 0.8899`.
- **Модель 2** (без признака `mileage` из-за высокой корреляции с `year`): `R² = 0.8802`.
- Обе модели показывают **высокое качество** (объясняют >88% дисперсии цены).
- Сформулировано математическое уравнение для предсказания цены.

**Визуализации:**
- Диаграммы рассеяния «Фактическая vs Предсказанная цена» для обеих моделей.

### 🛠 Используемые технологии

- **Язык программирования:** Python 3
- **Основные библиотеки:**
  - `pandas` — для анализа и обработки данных.
  - `numpy` — для числовых вычислений.
  - `matplotlib` и `seaborn` — для визуализации данных.
  - `scikit-learn` — для построения и оценки моделей машинного обучения (`LinearRegression`, `r2_score`).
- **Среда разработки:** Jupyter Notebook
