# 🚗 Прогнозирование цен на автомобили Toyota

Данный проект демонстрирует построение и сравнение двух линейных регрессионных моделей для предсказания рыночной стоимости подержанных автомобилей Toyota на основе ряда характеристик.

## 📌 Описание

Проект использует открытый набор данных `toyota.csv`, содержащий информацию о ~6700 автомобилях, включая год выпуска, пробег, тип топлива, налог, расход топлива и объём двигателя. Цель — предсказать цену (`price`) автомобиля.

Реализованы две модели:
- **Модель 1**: Использует все числовые признаки.
- **Модель 2**: Исключает один из сильно скоррелированных признаков (`mileage`) для улучшения устойчивости модели.

## 🛠️ Используемые технологии

- **Python** — основной язык программирования.
- **pandas** — для загрузки, очистки и анализа данных.
- **scikit-learn** — для построения и оценки моделей линейной регрессии.
- **matplotlib & seaborn** — для визуализации (остатки, диаграммы рассеяния).
- **Jupyter Notebook** — среда для разработки и демонстрации анализа.
- **Linear Regression** — основной алгоритм машинного обучения.

## 📊 Результаты

- **Модель 1 (все признаки)**: Коэффициент детерминации **R² = 0.7638**
- **Модель 2 (без `mileage`)**: Коэффициент детерминации **R² = 0.7387**

Хотя R² немного ниже у второй модели, она может быть предпочтительнее с точки зрения мультиколлинеарности.

## 🧪 Как запустить

1. Установите зависимости:
   ```bash
   pip install pandas scikit-learn matplotlib seaborn jupyter
   ```

2. Запустите Jupyter Notebook:
   ```bash
   jupyter notebook analysis.ipynb
   ```

3. Выполните все ячейки для воспроизведения анализа.
