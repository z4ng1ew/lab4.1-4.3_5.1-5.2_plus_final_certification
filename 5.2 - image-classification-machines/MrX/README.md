# Multi-Class Vehicle Image Classification

Проект по классификации изображений транспортных средств на 4 класса: **автобусы, легковые автомобили, мотоциклы и грузовики**. В проекте проведено сравнение нескольких архитектур нейронных сетей для оценки их эффективности на небольшом наборе данных.


## 📦 Используемые технологии

- **Python** - основной язык программирования.
- **TensorFlow / Keras** - фреймворки для глубокого обучения.
- **NumPy, Pandas** - библиотеки для научных вычислений и обработки данных.
- **Matplotlib, Seaborn** - библиотеки для визуализации данных.
- **scikit-learn** - для оценки качества моделей (матрица ошибок, отчеты классификации).

## 🧪 Сравниваемые архитектуры

В эксперименте были протестированы следующие модели:

1.  **Простая CNN**: Базовая сверточная нейросеть для сравнения.
2.  **Глубокая CNN**: Более сложная сверточная сеть с дополнительной регуляризацией (`Dropout`, `BatchNormalization`).
3.  **Transfer Learning (MobileNetV2)**: Использование предобученной модели MobileNetV2 с тонкой настройкой (`fine-tuning`). Показала наилучший результат.
4.  **Advanced CNN**: Глубокая функциональная модель с усилением регуляризации.
5.  **Deep CNN + SGD**: Та же глубокая CNN, но с оптимизатором SGD вместо Adam, для изучения его влияния.

## 🚀 Быстрый старт

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/your-username/vehicle-classification.git
    cd vehicle-classification
    ```

2.  **Создайте и активируйте виртуальное окружение (рекомендуется):**
    ```bash
    python -m venv venv
    # Linux/macOS
    source venv/bin/activate
    # Windows
    venv\Scripts\activate
    ```

3.  **Установите зависимости:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Подготовьте данные:**
    Структурируйте ваш датасет в формате, совместимом с `tf.keras.utils.image_dataset_from_directory`:
    ```
    your_dataset/
    ├── train/
    │   ├── Bus/
    │   ├── Car/
    │   ├── motorcycle/
    │   └── Truck/
    ├── validation/
    │   ├── Bus/
    │   ├── Car/
    │   ├── motorcycle/
    │   └── Truck/
    └── test/
        ├── Bus/
        ├── Car/
        ├── motorcycle/
        └── Truck/
    ```
    Затем укажите путь к корневой директории датасета в переменной `DATA_DIR` в скрипте.

5.  **Запустите обучение:**
    ```bash
    python vehicle_classification.py
    ```
    Скрипт автоматически обучит все указанные модели и выведет сравнительную таблицу и график точности.

## 📊 Результаты

Модель на основе **Transfer Learning (MobileNetV2)** показала наилучшую точность на тестовой выборке, значительно превзойдя простые и глубокие CNN, особенно на небольшом объеме данных.

---

**Рекомендация**: Для маленьких датасетов рекомендуется использовать **Transfer Learning**, так как это позволяет достичь высокой точности без длительного времени обучения и риска переобучения.
