# Vehicle Type Classification with Deep Learning

Этот проект представляет собой сравнительный анализ нескольких архитектур нейронных сетей для классификации транспортных средств на четыре класса: **автобус, легковой автомобиль, мотоцикл, грузовик**. Основной целью было достичь точности **выше 90%** на тестовой выборке, что успешно выполнено с использованием **Transfer Learning на базе MobileNetV2**.

## 📊 Результаты

| Модель                  | Точность на тестовой выборке |
| ----------------------- | ---------------------------- |
| **Transfer Learning**   | **0.9083**                   |
| Улучшенная CNN          | 0.5750                       |
| Простая CNN             | 0.5750                       |
| Глубокая CNN            | 0.2500                       |

> **Лучшая модель:** Transfer Learning (MobileNetV2) с точностью **~91%**, что превышает поставленную цель в 90%.

## 🛠️ Технологии и инструменты

Проект реализован на языке **Python** с использованием следующего стека технологий:

- **Глубокое обучение:** `TensorFlow` / `Keras`
- **Предобработка данных:** `NumPy`, `pandas`
- **Визуализация:** `matplotlib`, `seaborn`
- **Работа с изображениями:** Встроенные утилиты Keras для загрузки и аугментации данных
- **Transfer Learning:** Предобученная модель `MobileNetV2`
- **Метрики и оценка:** Генерация отчетов о классификации (`sklearn.metrics.classification_report`)

## 🧪 Модели

В рамках проекта были протестированы четыре разных подхода:

1.  **Простая CNN:** Базовая сверточная сеть для демонстрации стартовой точки.
2.  **Глубокая CNN:** Более сложная архитектура с несколькими сверточными слоями и `BatchNormalization`. Показала нестабильные результаты.
3.  **Улучшенная CNN:** Глубокая CNN с добавленными регуляризационными техниками, такими как `Dropout` и улучшенная стратегия подбора скорости обучения.
4.  **Transfer Learning (MobileNetV2):** Использование предобученной на ImageNet модели MobileNetV2 в качестве feature extractor с добавлением собственного классификатора. Эта модель продемонстрировала наилучшие результаты.
