# Лабораторные работы по машинному обучению

Данный репозиторий содержит решения трёх лабораторных работ, выполненных в рамках курса по машинному обучению. Каждая работа фокусируется на отдельной задаче: анализ временных рядов, регрессия и классификация.

## Структура проекта

Проект разделён на три основные директории:

*   **`4.1 - lab8-global-co2-analysis`** — Анализ исторических данных о выбросах CO₂.
*   **`4.2 - lab8-car-price-prediction`** — Построение модели машинного обучения для прогнозирования цены подержанного автомобиля.
*   **`4.3 - credit-default-prediction`** — Построение модели для прогнозирования вероятности дефолта по кредиту.

Каждая директория содержит:
*   Свою отдельную папку для каждого участника (`Apache`, `MrX`, `Vas`) с их реализацией в формате Jupyter Notebook (`.ipynb`).
*   Необходимые для анализа и обучения датасеты (`.csv`).
*   Специфическое задание в формате PDF.
*   Локальный `README.md` с деталями по конкретной работе (при наличии).

## 1. Анализ глобальных выбросов CO₂ (4.1)

**Цель:** Провести исследовательский анализ данных (EDA) по историческим выбросам углекислого газа, выявить ключевые тенденции и визуализировать результаты.

**Задачи:**
*   Загрузка и предварительная обработка датасета `owid-co2-data.csv`.
*   Анализ суммарных выбросов по странам и определение лидера.
*   Исследование динамики выбросов по десятилетиям.
*   Анализ выбросов по континентам.
*   Построение наглядных графиков для представления результатов.

**Используемые технологии:** `pandas`, `numpy`, `matplotlib`, `seaborn`.

---

## 2. Прогнозирование цены автомобиля (4.2)

**Цель:** Построить, обучить и оценить регрессионную модель для прогнозирования стоимости подержанного автомобиля Toyota.

**Задачи:**
*   Загрузка и анализ датасета `toyota.csv` (признаки: год выпуска, пробег, тип топлива и др.).
*   Построение двух моделей линейной регрессии: на всех признаках и с исключением одного из-за мультиколлинеарности.
*   Оценка качества моделей с помощью коэффициента детерминации R².
*   Сравнение моделей и составление прогноза для нового автомобиля.
*   Визуализация результатов (графики фактической vs. прогнозируемой цены).

**Используемые технологии:** `pandas`, `numpy`, `scikit-learn`, `matplotlib`, `seaborn`.

---

## 3. Прогнозирование кредитного дефолта (4.3)

**Цель:** Построить модель машинного обучения для бинарной классификации, предсказывающей вероятность дефолта клиента по кредиту.

**Задачи:**
*   Загрузка и предварительная обработка датасета (например, `german_credit_data.csv`).
*   Инженерия признаков, кодирование категориальных переменных.
*   Обучение и сравнение нескольких моделей (например, Логистическая регрессия, Random Forest).
*   Оценка качества моделей с помощью метрик: `classification_report`, `ROC-AUC`, `confusion matrix`.
*   Создание функции для предсказания дефолта для нового клиента на основе его данных.

**Используемые технологии:** `pandas`, `numpy`, `scikit-learn`, `matplotlib`, `seaborn`.
