# Лабораторные работы по машинному обучению

Данный репозиторий содержит решения лабораторных работ, выполненных в рамках курса по машинному обучению. Проект охватывает широкий спектр задач: от анализа временных рядов и регрессии до бинарной классификации и современных методов глубокого обучения.

## Структура проекта

Проект организован по тематическим директориям. Каждая работа содержит решения от трёх участников (`Apache`, `MrX`, `Vas`) в формате Jupyter Notebook (`.ipynb`), а также сопутствующие материалы.

```
├── 4.1 - global-co2-analysis/          # Анализ исторических выбросов CO₂
├── 4.2 - car-price-prediction/         # Прогнозирование цены подержанного автомобиля
├── 4.3 - credit-default-prediction/    # Прогнозирование вероятности кредитного дефолта
├── 5.1 - fashion-mnist-comparison/     # Сравнение архитектур CNN на Fashion-MNIST
├── 5.2 - image-classification-machines/ # Классификация изображений техники с использованием MobileNet
└── Итоговая аттестационная работа/     # Презентация и код для итогового проекта
```

## Описание лабораторных работ

### **4.1 — Анализ глобальных выбросов CO₂**
**Цель:** Провести исследовательский анализ данных (EDA) по историческим выбросам углекислого газа на основе датасета от Our World in Data.
- **Задачи:** Анализ суммарных выбросов по странам, исследование динамики по десятилетиям, сравнение по континентам, визуализация ключевых трендов.

### **4.2 — Прогнозирование цены автомобиля**
**Цель:** Построить и сравнить регрессионные модели для прогнозирования стоимости подержанного автомобиля Toyota.
- **Задачи:** Обработка данных, построение моделей линейной регрессии, оценка качества с помощью метрики R², прогнозирование для новых данных.

### **4.3 — Прогнозирование кредитного дефолта**
**Цель:** Разработать модель бинарной классификации для оценки вероятности дефолта клиента.
- **Задачи:** Инженерия признаков, обработка несбалансированных данных, сравнение моделей (Логистическая регрессия, Random Forest), оценка через ROC-AUC и матрицу ошибок.

### **5.1 — Сравнение архитектур CNN на Fashion-MNIST**
**Цель:** Сравнить производительность различных архитектур свёрточных нейронных сетей (CNN) на стандартном датасете Fashion-MNIST.
- **Задачи:** Обучение и валидация нескольких CNN-моделей, анализ точности и потерь, оптимизация с помощью Batch Normalization и Dropout.

### **5.2 — Классификация изображений техники**
**Цель:** Построить модель для классификации изображений различных видов транспортных средств и техники.
- **Задачи:** Применение трансферного обучения с использованием предобученной архитектуры MobileNet, тонкая настройка модели, оценка качества классификации.

### **Итоговая аттестационная работа**
**Цель:** Комплексный сравнительный анализ архитектур CNN для задачи классификации транспортных средств.
- **Содержит:** Презентацию (`*.pptx`) с подробным анализом и Jupyter Notebook с полным кодом исследования.
