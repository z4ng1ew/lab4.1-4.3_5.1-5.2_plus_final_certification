# Анализ исторических выбросов CO₂ (1750–2017)

![Python](https://img.shields.io/badge/Python-3.11%2B-blue?logo=python)
![Pandas](https://img.shields.io/badge/Pandas-2.0%2B-white?logo=pandas)
![Matplotlib](https://img.shields.io/badge/Matplotlib-3.7%2B-orange?logo=matplotlib)
![Jupyter](https://img.shields.io/badge/Jupyter-Notebook-yellow?logo=jupyter)

Этот проект посвящён всестороннему анализу глобальных исторических выбросов углекислого газа (CO₂) за период с 1750 по 2017 год. На основе открытых данных от [Our World in Data](https://ourworldindata.org/co2-and-other-greenhouse-gas-emissions) проводится исследование динамики выбросов на глобальном, страновом и континентальном уровнях.

## 📊 Цели проекта

- Выявить долгосрочные тенденции в глобальных выбросах CO₂ по десятилетиям.
- Определить страны-лидеры по совокупным историческим выбросам.
- Проследить динамику годовых выбросов в топ-5 стран-эмитентов.
- Проанализировать распределение выбросов по континентам на последний доступный год данных.

## 🛠 Используемые технологии

- **Python 3.11+**: основной язык программирования.
- **Pandas**: для загрузки, очистки и агрегации данных.
- **Matplotlib**: для создания статических, публикационно-готовых визуализаций.
- **Jupyter Notebook**: среда для разработки, анализа и документирования кода.
- **NumPy**: для работы с числовыми массивами и вычислениями.

## 📁 Структура проекта

- `owid-co2-data.csv` — исходный датасет с историческими данными о выбросах CO₂.
- `co2_analysis.ipynb` — Jupyter Notebook, содержащий весь код анализа и визуализации.
- `график_*.png` — сгенерированные изображения, иллюстрирующие ключевые выводы исследования.

## 📈 Генерируемые визуализации

1. **Декадная динамика выбросов**: показывает экспоненциальный рост глобальных выбросов с XIX века.
2. **Топ-10 стран по совокупным выбросам**: ранжирует страны по их историческому вкладу в общее количество CO₂ в атмосфере.
3. **Эволюция годовых выбросов в топ-5 стран**: строит временные ряды для США, Китая, России, Германии и Великобритании.
4. **Континентальное распределение (2017 г.)**: визуализирует долю каждого континента в глобальных выбросах за последний год наблюдений.

## 📥 Данные

Исходные данные взяты из открытого репозитория **Our World in Data**. Вы можете скачать актуальную версию датасета по [этой ссылке](https://github.com/owid/co2-data).

## 📌 Выводы

Анализ подтверждает, что промышленная революция стала отправной точкой для стремительного роста антропогенных выбросов. Лидирующую роль в историческом накоплении CO₂ сыграли развитые экономики, такие как США и страны Европы. Однако в последние десятилетия наблюдается значительный рост выбросов в странах Азии, в первую очередь в Китае.
