## 🌍 Анализ исторических выбросов CO₂ (1750–2017)

Проект по исследованию глобальных выбросов углекислого газа на основе публичного датасета Our World in Data.  
Основная цель — выявить ключевых эмитентов, проследить динамику по десятилетиям и континентам, а также представить данные в наглядной визуальной форме.

---

### 📌 Ключевые результаты

- **Страна-лидер по совокупным выбросам**: США (434.87 гигатонн CO₂).
- **Топ-5 эмитентов**: США, Китай, Россия, Германия, Великобритания.
- **Континент с наибольшими выбросами в 2024 г.**: Азия (62.5% от анализируемого массива).
- Выявлены **резкие скачки выбросов** в XX веке, особенно в 1950–1960-х и 2000–2010-х годах.

---

### 📊 Визуализации

В результате работы сгенерированы четыре основные визуализации:

1. **`viz_1_декады.png`** – динамика глобальных выбросов по десятилетиям.
2. **`viz_2_рейтинг_стран.png`** – топ-10 стран по совокупным выбросам.
3. **`viz_3_временные_ряды.png`** – временные ряды для пяти крупнейших эмитентов.
4. **`viz_4_континенты.png`** – распределение выбросов по континентам в последнем году наблюдений.

### ⚙️ Используемые технологии

- **Язык программирования**: Python 3
- **Основные библиотеки**:
  - `pandas` — загрузка, очистка и агрегация данных
  - `matplotlib` — построение графиков и визуализаций
  - `numpy` — математические операции
- **Инструментарий**: Jupyter Notebook
